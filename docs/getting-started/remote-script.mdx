目标：不用 Agent 对话，直接通过脚本在 Windows 云桌面启动记事本。

## 准备

先创建[管理员 Client](/getting-started/initialize-client#管理员创建-client)。目标桌面已开机，提供真实 `desktopId` 与 `regionId`；本例使用支持 PowerShell 的 Windows 桌面。

先下载对应语言的等待函数：[Node run-script.mjs](/downloads/examples/quickstart/run-script.mjs.txt)、[Go run-script.go](/downloads/examples/quickstart/run-script.go.txt) 或 [Java RunScript.java](/downloads/examples/quickstart/RunScript.java.txt)，去掉下载后缀 `.txt` 并放在示例目录，Go 使用同一 package。它们是随文档提供的 demo helper，不是 SDK 内置方法；负责等待 completed、检查 allSucceeded、保存受理标识并释放本地订阅，不重发未知结果的脚本。

## 启动应用

<CodeGroup>

```ts TypeScript
import { runScript } from './run-script.mjs';

const commandContent = 'Start-Process notepad.exe -PassThru | Select-Object Id, ProcessName';
const runtimes = await admin.buildRuntimeManager(ctx);
const results = await runScript(runtimes, {
  regionId, desktopIds: [desktopId], type: 'RunPowerShellScript', commandContent,
}, ctx);
console.log(results[0].output);
```

```go Go
commandContent := "Start-Process notepad.exe -PassThru | Select-Object Id, ProcessName"
runtimes, err := admin.BuildRuntimeManager(ctx)
if err != nil { return err }
results, err := RunScript(ctx, runtimes, &model.RunCommandRequest{
    RegionID: regionID, DesktopIDs: []string{desktopID}, Type: "RunPowerShellScript", CommandContent: commandContent,
})
if err != nil { return err }
fmt.Print(results[0].Output)
```

```java Java
String commandContent = "Start-Process notepad.exe -PassThru | Select-Object Id, ProcessName";
RuntimeManager runtimes = admin.buildRuntimeManager(ctx);
RunCommandRequest request = new RunCommandRequest();
request.regionId = regionId;
request.desktopIds = Collections.singletonList(desktopId);
request.type = "RunPowerShellScript";
request.commandContent = commandContent;
List<CommandDesktopResult> results = RunScript.run(runtimes, request, ctx);
System.out.print(results.get(0).output);
```

预期脚本结果：桌面状态为 `Success`，退出码为字符串 `"0"`，输出包含新进程的 ID 与名称。等待函数只在所有目标桌面都成功时返回；调用失败或脚本失败按错误处理。

应用能否出现在当前桌面画面中，取决于脚本执行身份和 Windows 交互会话。部署方应确认命令进入目标用户的桌面会话；SDK 不自动提升权限或把系统会话切换为当前用户。通过[ASP 示例](/getting-started/asp)连接同一桌面，核对记事本窗口是否可见；脚本成功与窗口可见分别验证。

## 直接提交请求

把同样的请求保存为 `script.json`：

```json
{
  "regionId": "cn-hangzhou",
  "desktopIds": ["YOUR_DESKTOP_ID"],
  "type": "RunPowerShellScript",
  "commandContent": "Start-Process notepad.exe -PassThru | Select-Object Id, ProcessName"
}
```

<DemoRunCommand />

替换实际地域和桌面。此处 `admin` profile 使用管理员 AK/SK 或已配置的 OAuth。关注 accepted 回执和 completed 的 `allSucceeded`；不要将 accepted 当成启动完成。

## 恢复和清理

保留回执中的 `invokeId`；断线后用 [`subscribeCommand`](/api-reference/runtimes/subscribe-command)读取原结果，不自动重发 `Start-Process`。关闭 Client 或停止本地订阅不关闭已启动的记事本；演示结束可在桌面中正常关闭应用。

完整脚本类型、权限、事件和超时说明见[远程脚本](/domain-model/remote-script)。
