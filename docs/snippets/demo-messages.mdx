`client`、`ctx`、真实 runtimeId / conversationId 由宿主提供。Go listener 为 `model.SubscriptionListener[model.Page[model.Message]]`，Java 为 `SubscriptionListener<Page<Message>>`；移动端 onEvent 先处理 error，再消费 snapshot 的 data 与 projection。取消语句在页面退出时执行。

```ts TypeScript
const conversations = await client.buildConversationManager(ctx);
const subscription = await conversations.subscribeMessages(ctx, { runtimeId, conversationId }, {
  onSnapshot: renderMessages, onError: showError,
});
// 页面离开时
subscription.unsubscribe();
```

```go Go
conversations, err := client.BuildConversationManager(ctx)
if err != nil { return err }
ref := model.ConversationRef{RuntimeRef: model.RuntimeRef{RuntimeID: runtimeID}, ConversationID: conversationID}

subscription.Unsubscribe()
```
