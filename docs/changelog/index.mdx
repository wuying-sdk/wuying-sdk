## 2026-11-12：管理员 OAuth、ASP 桌面与 Harness

- 基础提交更新至 05bd99e，保留已有 RuntimeManager 首版调整。
- Node / CLI 新增管理员 OAuth、动态凭据 Provider / STS 签名与官方凭据刷新适配。
- CLI 新增 asp open，可在浏览器交互桌面，并提供面向本地 GUI 的私有管道交接。
- 新增 DeepSeek Harness 0.3.1 集成指南：七个模型工具、组织账号页及 ASP 侧栏。
- 配套 Skill 增加 cloud-operations 引用，安装器与下载包包含同一份说明。

## 2026-11-11：组织账号登录与 Runtime 命令

- 基础提交更新至 4b855bc，保留 RuntimeManager 首版调整与配套 Skill。
- JS / Go / Java 新增组织账号密码登录，CLI 新增 auth login --stdin；权限分类仍为管理员与用户态两类。
- RuntimeManager 新增管理员 runCommand / observeCommand，文档说明逐桌面事件、输出快照、终态和断线恢复。
- CLI Skill 同步命令执行与只读恢复；Android / iOS 未声明这些新入口。

## 2026-11-11：CLI 配套客户 Skill

- 随 CLI 提供云资源管理和远程 Agent 任务两项 Skill，包含对应 references。
- 安装命令支持同时安装、更新两项 Skill，并检查客户自有目录和符号链接冲突。
- 文档新增安装、使用与升级指南，并从同一源码归档生成 Skill 下载包。


## 2026-11-11：CLI 管理员认证与云桌面管理

- 更新基础提交至 ea48f87，保留 RuntimeManager 本地草稿。
- CLI 新增 AK/SK 凭据模式、desktops create / wait / start / stop / reboot / reset / delete，以及 auth code。
- API Reference 将命令关联到同一根 Client 业务操作；Android/iOS 清单未增加这些生命周期操作。


## 2026-11-11 · Runtime 基础管理更新

- 引用基础提交 f9f6325 及本地 RuntimeManager 草稿，保留当前四类能力划分。
- Runtime 领域补充开机、关机、重启、重置和释放；实际公开入口为根 Client。
- 说明用户态与 AK/SK 的权限、镜像参数和受理结果差异，补充 TS、Go、Java 核心示例。
- 通用 ResourceSelection 明确标为预留接口，当前生产集成返回 UNSUPPORTED。

## 2026-11-11 · RuntimeManager 首版草稿

- 源码基线迁至 `codex/admin-aksk-client`，保留 AK/SK 管理员态与用户态身份隔离。
- RuntimeManager 统一环境目录、能力及资源操作；公开列表只保留 listRuntimes。
- 移除 CloudAgentManager、重复列表 listAgentInstances 及其专用 DTO；移动端同步为 113 个入口。
- Runtime 使用一个领域介绍页；SDK 方法名按实际代码展示。
- 当前为未提交源码与本地文档预览，不代表公开发布或新原生制品已经验收。
