当前共有 **113 个 JSON 方法入口**。调用方式为 `Client.request` 加 `Methods` 常量，并非每个方法都有同名 Java / Swift 成员函数。公开包装类型见 [Client 与事件](/reference/ios/client)。这份清单与服务端 Java SDK、JS SDK 分别核对，不代表功能完全相同。

| 模型 | 方法数 |
|---|---:|
| [AgentManager](/reference/ios/models/agent) | 14 |
| [ConversationManager](/reference/ios/models/conversation) | 64 |
| [CreditManager](/reference/ios/models/credit) | 2 |
| [ModelManager](/reference/ios/models/model) | 2 |
| [ResourceManager](/reference/ios/models/resource) | 17 |
| [RuntimeManager](/reference/ios/models/runtime) | 8 |
| [SkillManager](/reference/ios/models/skill) | 6 |

两个移动端共用同一清单，重复计数不表示新增独立业务能力。五项通用 Resource 目录/绑定方法保留 UNSUPPORTED 状态。新云管理入口也需对应版本的原生制品与上游能力支持。
