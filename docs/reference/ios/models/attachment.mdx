## Methods.attachmentAttachCloudFile

`Methods.attachmentAttachCloudFile` → `attachment.attachCloudFile`

**模式：** `call`。**请求类型：** `m.AttachCloudFileRequest`。**MutationOptions：** 不支持；省略 `mutationId`。

```go
*AttachmentManager.AttachCloudFile
func(ctx context.Context, r m.AttachCloudFileRequest) (m.Attachment, error)
```
