在应用中通过根包导入公开类型，而不是从本站下载路径或 SDK 私有目录建立运行时依赖。请以实际安装交付包的声明和能力为准。

## 返回形状

| 形状 | 读取方式 |
| --- | --- |
| `Snapshot<T[]>` | 列表在 `snapshot.data` |
| `Snapshot<Page<T>>` | 消息等分页列表在 `snapshot.data.items`，保留 `nextCursor` |
| 直接 DTO | 按具体方法返回类型读取，不套用固定 `data.items` 路径 |
| `Subscription` | 在当前观察者结束时释放，不结束其他页面共用的 Client |

`projection`、分页游标、真实 ID、版本和 Capability 应随业务数据一起处理。详见[投影与事件](/domain-model/10-projection-events)。
