## Methods.resourceAttachImGroupFile

`Methods.resourceAttachImGroupFile` → `resource.attachImGroupFile`

**模式：** `call`。**请求类型：** `m.IMGroupFileRequest`。**MutationOptions：** 不支持；省略 `mutationId`。

```go
*ResourceManager.AttachImGroupFile
func(ctx context.Context, r m.IMGroupFileRequest) (m.IMGroupAttachmentResult, error)
```
