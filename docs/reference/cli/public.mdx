本页完整列出当前快照中的公开函数、方法与命令，包含重载。业务操作按模型拆页；构造、配置、DTO/错误辅助、回调契约等保留完整签名，不当作新的资源操作。

统计当前 CLI 显式注册的所有命令及子命令。分组入口与可执行叶命令分别列出；以下签名来自静态注册，不执行命令。

## 全局选项

```sh
optional --profile <name> — Credential and database profile (default: default)
optional --data-dir <directory> — Private CLI data directory (or WUYING_CLI_HOME)
optional --output <format> — json, jsonl, or text (default: json)
optional --timeout <milliseconds> — Local wait deadline; never cancels a remote task (default: 120000)
optional --no-input — Never prompt (v0.1 always uses explicit inputs)
```

以上为通用注册默认值；asp open 未显式传 --timeout 时，生命周期覆盖为 3600000ms（1小时）。

CLI 框架的 help / --help 与 --version 用于查看帮助和版本，不计作业务 API；以安装包帮助为准。
