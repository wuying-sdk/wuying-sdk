## interactions list

```sh
wuying interactions list
required --runtime <id> — Explicit authorized Runtime ID
required --conversation <id> — Product Conversation ID
optional --limit <count> — Page size (1..100) (default: 50)
optional --cursor <cursor> — Opaque nextCursor
```

[查看操作或完整契约](/api-reference/interactions/list)

## interactions respond

```sh
wuying interactions respond
required --runtime <id> — Explicit authorized Runtime ID
required --conversation <id> — Product Conversation ID
required --interaction <id> — Interaction ID
required --expected-version <version> — Current interaction writeVersion
optional --option <id> — Permission option ID
optional --answer-file <path> — Question answer JSON: {answers:[...]} or {skip:true}
```

[查看操作或完整契约](/api-reference/cli/interactions-respond)
