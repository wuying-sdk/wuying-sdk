## messages get

```sh
wuying messages get
required --runtime <id> — Explicit authorized Runtime ID
required --conversation <id> — Product Conversation ID
required --message <id> — Message ID from the Turn
optional --limit <count> — Process-item page size (default: 50)
optional --cursor <cursor> — Opaque nextCursor
```
