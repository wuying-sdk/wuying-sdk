## conversations create

```sh
wuying conversations create
required --runtime <id> — Explicit authorized Runtime ID
required --agent <id> — Agent ID
required --name <name> — Conversation title
optional --mutation-id <id> — Stable ID for retrying the same create request
```

[查看操作或完整契约](/api-reference/conversations/create)

## conversations get

```sh
wuying conversations get
required --runtime <id> — Explicit authorized Runtime ID
required --conversation <id> — Product Conversation ID
optional --consistency <mode> — cache or refresh (default: cache)
```
