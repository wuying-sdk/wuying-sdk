Workspace 定位授权执行环境中的工作空间引用，为会话提供工作范围与展示元数据。

## 模型与关联

`Workspace` / `WorkspacePage` 描述公开工作空间，`ConversationHeaderMetadata` / `ConversationStorageContext` 描述会话可读的工作区信息。

会话可按能力引用 workspaceId；云文件属于 [WyDrive](/domain-model/wy-drive)，消息产物见 [MessageCloudFile](/domain-model/message-cloud-file)，不是 Workspace 的同义对象。

## 生命周期

选择或创建 Workspace → 在会话创建时按能力引用 → 读取该会话工作区元数据 → 随真实状态更新展示。

## 操作入口

- [`listWorkspaces`](/api-reference/workspaces/list)
- [`createWorkspace`](/api-reference/workspaces/create)
- [`getConversationHeaderMetadata`](/api-reference/conversations/get-conversation-header-metadata)
- [`getConversationStorageContext`](/api-reference/workspaces/get-conversation-storage-context)

## 使用边界

displayPath 用于展示，不授予任意远程文件系统写权限。公共 Workspace 接口不等于 demo 文件树或预览代理；云盘删除也不等于工作空间文件修改。

精确类型与语言差异见 [SDK Reference](/sdk-reference/index)。
