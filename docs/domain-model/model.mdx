Model 领域读取云实例的模型目录与配置；会话和成员的模型选择通过各自的配置接口完成。

## 模型与关联

ModelManager 提供云实例模型目录和配置查询。会话模型选择使用 ConversationManager.setConversationConfigOption 的 model 选项；成员模型通过成员配置接口设置。

[Agent](/domain-model/agent) 提供可选 Model / AgentModelCatalog；[Config](/domain-model/config) 与 [Member](/domain-model/04-member-config) 分别解释会话和成员级配置。

## 生命周期

核对云实例身份与作用域 → 读取模型目录与配置 → 根据实际会话或成员选择可用模型。

## 操作入口

- [`getAgentInstanceModelConfig`](/api-reference/models/get)

## 使用边界

不能用 conversationId 替代独立云配置要求的身份。CLI 的 models list 查询 Agent 可用模型；ModelManager 读取的是独立云实例配置，不提供旧 Channel Group 模型写入操作。

精确类型与语言差异见 [SDK Reference](/sdk-reference/index)。
