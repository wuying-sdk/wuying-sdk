Model 领域管理独立的云模型配置，不替代某次会话或某个成员的模型选择。

## 模型与关联

ModelManager 提供云实例模型配置与渠道分组模型配置操作。

[Agent](/domain-model/agent) 提供可选 ModelSummary / AgentModelCatalog；[Config](/domain-model/config) 与 [Member](/domain-model/04-member-config) 分别解释会话和成员级配置。

## 生命周期

核对云配置的真实实例与作用域 → 读取配置 → 在允许范围内提交 → 按接口结果核对。

## 操作入口

- [`getAgentInstanceModelConfig`](/api-reference/models/get)
- [`setChannelGroupModel`](/api-reference/models/set-channel-group-model)

## 使用边界

不能用 conversationId 替代独立云配置要求的身份。CLI 的 models list 查询 Agent 可用模型，不等于 ModelManager 修改云配置。

精确类型与语言差异见 [SDK Reference](/sdk-reference/index)。
