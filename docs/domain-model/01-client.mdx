## 领域职责

Client 是当前身份下访问 SDK 的根入口，统一取得业务 Manager、维护连接与本地副本。Manager 是调用入口，不是另一个账号或独立登录会话。

## 关键模型与关联

| 模型 | 关键含义 | 调用方负责 |
|---|---|---|
| ClientOptions | 管理员 AK/SK；用户态 AuthCode、完整 loginToken/sessionId/endUserId 或组织账号密码（三选一），按需提供登录地域 | 从宿主认证系统安全注入，不在 Web 放置 AK/SK |
| 配置对象 | 授权 Client ID、数据位置、日志及 SDK 配置 | 为账号/环境选择独占的可写数据位置 |
| Context / CallContext / context.Context | 调用期限、取消和可选追踪元数据 | 不把本地等待结束解释成远端已取消 |
| Subscription | 本地订阅句柄 | 页面退出退订；不关闭其他组件共享的 Client |

表中是领域含义，不是可跨语言逐字复制的 JSON。JS 的 Client.create 同步返回 Client，准备/查询可能异步失败；Java 使用 WuyingClient，Go 使用 NewClient；CLI 由每条命令管理连接和 profile。

## 生命周期

宿主登录 → 创建根 Client → 查询并订阅业务 → 页面退出释放所属订阅 → 账号退出关闭 Client。更换身份应按本语言合同建立新的 Client 和隔离存储，不并发打开同一持久库，也不直接修改 SDK 内部库。

AuthCode 可能短效/一次性消费。SDK 管理其认证、续期和连接；客户端不另建 token 刷新器。CLI auth status 只检查配置，在线身份使用 doctor 核对；POSIX 凭据文件与 Windows 环境注入的差异见 [认证指南](/integration/01-auth-and-lifecycle)。

## 公开入口

| 任务 | JS | Go | Java | CLI |
|---|---|---|---|---|
| 建立根入口 | Client.create | NewClient | new WuyingClient | 由命令建立会话 |
| 取得环境目录与云资源 | buildRuntimeManager | BuildRuntimeManager | buildRuntimeManager | runtimes |
| 取得 Agent 目录 | buildAgentManager | BuildAgentManager | buildAgentManager | agents |
| 取得会话业务 | buildConversationManager | BuildConversationManager | buildConversationManager | conversations / messages / turns |
| 取得资源业务 | buildResourceManager | BuildResourceManager | buildResourceManager | run --attach（部分能力） |
| 释放身份生命周期 | close | Close | close | 当前命令退出；auth logout 仅本地凭据处理 |

## 调用期限

JS 普通请求与长流分别遵循其 Context 的合法范围，不能把长流的超时直接复用于建会或普通查询。Go/Java 使用各自的 context/deadline；精确范围和关闭语义查看本语言参考。取消订阅、关闭 Client、取消 Turn 是不同操作。

## 边界与示例

Node 需要真实持久 IndexedDB 能力（本包示例使用指定 shim），浏览器需要其原生能力。JS / Go / Java 根 Client 已支持组织账号密码登录；它仍是无影用户态，不授予管理员权限。MFA、SSO 或改密挑战返回 LOGIN_CHALLENGE_REQUIRED，当前 SDK 不承接后续挑战。Android / iOS 移动配置未开放密码登录。安装/只读示例见 [语言绑定](/domain-model/language-bindings)，通用细节见 [认证与生命周期](/integration/01-auth-and-lifecycle)。
