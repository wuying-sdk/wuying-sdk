KnowledgeSpace 描述当前 Agent 可访问的知识空间目录。

## 模型与关联

AgentManager 按合法作用域列出知识空间；空间中的文件由 [KnowledgeFile](/domain-model/knowledge-file) 表达。

[Agent](/domain-model/agent)、会话配置及资源选择各有独立能力边界。

## 生命周期

选择 Runtime / Agent → 查询已授权知识空间 → 选择真实空间 → 查询文件。

## 操作入口

- [`listAgentKnowledgeSpaces`](/api-reference/knowledge/list-agent-knowledge-spaces)

## 使用边界

知识空间存在不表示通用 ResourceSelection 已支持将其绑定会话；不要根据名称伪造空间 ID 或默认授权。

精确类型与语言差异见 [SDK Reference](/sdk-reference/index)。
