## 调用与模型使用

SDK DTO 是领域的当前公开投影，不是数据库 schema。不同语言不按字段大小写机械互译；真实 ID、版本、游标和可用性按返回值处理。CLI 的输出还有命令 envelope，不能把 JS 的 data 路径直接套到每条 CLI 命令。

示例的默认帮助不调用业务。显式 --send 才根据宿主授权配置建会/发送；旧 TypeScript 组合函数用于演示订阅释放，不示范完整幂等恢复，稳定 mutation/command 身份见新的 runnable workflow 和本语言指南。
