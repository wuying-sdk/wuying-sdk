---
title: "读取查询结果"
description: "列表读取 items，观察事件和部分详情查询保留同步状态。"
---

列表查询统一从 `items` 读取这一页，从 `nextCursor` 继续查询，无需读取 `result.data`。

```ts
const agents = await client.buildAgentManager(ctx);
const result = await agents.listAgents(ctx, { runtimeId });
const items = result.items;
```

部分列表还提供 `projection`，说明当前数据的同步状态。空页可能来自尚未同步完整的目录；`nextCursor` 为 `null` 也不证明同步已经完成。完整续查规则见[列表查询与分页](/domain-model/page)。

## 观察事件与详情查询

观察接口 `observe*` 仍发送 `Snapshot`，其中 `data` 是本次观察到的数据，`projection` 是它的同步状态。部分详情查询也使用这一结构，以对应接口签名为准。

```ts
const subscription = await agents.observeAgents(ctx, { runtimeId }, {
  onSnapshot: ({ data, projection }) => renderAgents(data, projection),
  onError: showError,
});
```

下一步见[判断数据是否可用](/domain-model/projection)。
