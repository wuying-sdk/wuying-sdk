description: "查询返回值里的实际数据放在哪里。"
---

部分查询返回 Snapshot，需要读取其中的 `data`。`Snapshot` 是“本次读到的数据，加上这份数据的状态”，不是另一种业务资源。

```ts
const agents = await client.buildAgentManager(ctx);
const snapshot = await agents.listAgents(ctx, { runtimeId });
const items = snapshot.data;
```

消息分页的读取方式不同：`snapshot.data.items` 是这一页的消息，`snapshot.data.nextCursor` 用来继续读取。返回路径以具体方法的签名为准，不能把所有接口都当作 `data.items`。

还要检查 `snapshot.projection`：空数组可能来自尚未同步完成的结果，并不一定表示用户没有资源。下一步见[判断数据是否可用](/domain-model/projection)。

## Runtime 目录查询

`listRuntimes` 直接返回 Runtime 数组，不使用 Snapshot 包装。本文的 .data / projection 用法适用于实际声明仍返回 Snapshot 的其它接口；`observeRuntimes` 仍携带同步状态。
