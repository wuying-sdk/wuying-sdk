---
title: "实时观察与停止监听"
description: "观察同一会话的最新结果，并在退出时释放自己的订阅。"
---

聊天界面需要随消息变化更新时，使用 observe 类方法。`Subscription` 是返回的本地监听句柄；页面退出时通过它停止监听。

```ts
const conversations = await client.buildConversationManager(ctx);
const subscription = await conversations.observeMessages(ctx, {
  runtimeId, conversationId,
}, {
  onSnapshot: renderMessages,
  onError: showError,
});

subscription.unsubscribe();
```

`renderMessages` 和 `showError` 由应用实现，最后一行在页面退出或切换会话时调用。每次回调是一份当前查询范围的快照，应按稳定消息 ID 更新界面，不把整页重复追加。

停止监听只结束本地观察，不取消远端任务，也不关闭其他页面共享的 Client。Android/iOS 使用自己的 Request 管理本地生命周期，见[移动端契约](/reference/mobile/contract)。
