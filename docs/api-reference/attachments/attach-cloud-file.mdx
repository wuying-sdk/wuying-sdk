`attachCloudFile` · Attachment

## 接口用途

将当前会话云盘中已上传的文件导入为会话附件，并支持通过原请求恢复结果。

## 使用说明

导入当前会话关联云盘中已完成的普通文件（1..10MiB），返回 Attachment，可将 attachmentId 用于同会话发送消息。第一次调用前保存 UUID clientCommandId、runtimeId、conversationId 和完整 file 引用；结果未知时以同一请求再次调用，Gateway 复用原持久回执和附件。SDK 不自动循环重试，不重新上传文件或发送消息。更换文件或存储环境须作为新的明确操作；不要在结果未知时更换请求标识。file 仅包含 regionId、driveId、fileId 和可选 storageEnvironment（online/pre）；不接受 URL、任意云盘/知识库文件或客户端文件属性。导入的 clientCommandId 不用于 getCommandReceipt，导入恢复继续调用 attachCloudFile；消息发送未知时使用发送请求的独立标识查询消息回执。原有 Gateway 认证、文件校验与幂等 owner 不变。
