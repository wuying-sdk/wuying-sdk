`getTurn` · Turn

使用受理返回的真实 turnId；区分 active 与具体终态，不能按消息气泡数推断执行完成。

| 语言 | 公开入口 | 状态 |

| JavaScript / TypeScript | `ConversationManager.getTurn` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go/manager.ConversationManager.GetTurn` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.manager.ConversationManager.getTurn` | 已公开声明，需核对环境能力 |

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

interface ConversationRef extends RuntimeRef {
    conversationId: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface Snapshot<T> {
    data: T;
    projection: Projection;
}

interface Turn extends ConversationRef {
    turnId: string;
    messageIds: string[];
    state: 'active' | 'completed' | 'cancelled' | 'failed' | 'interrupted' | 'unknown';
    errorCode?: string;
    revision: Int64;
}
```
