`setChannelGroupModel` · Model

云管理 API：设置云端 channel group 模型，不接受 Gateway Conversation ID。
新版会话请调用 ConversationManager.setConversationConfigOption(model)。
支持同步和异步模式（通过 CallOption）

同步用法：
  const result = await mgr.setChannelGroupModel(ctx, \{
    agentInstanceId: 'inst-xxx', groupId: 'grp-xxx',
    providerName: 'bailian', llmCode: 'qwen3.5-plus',
  \});

异步用法：
  mgr.setChannelGroupModel(ctx, req, WithAsync((result, err) =&gt; \{ ... \}));
