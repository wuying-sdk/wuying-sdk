`listRuntimes` · Runtime

返回 Runtime 分页列表，读取 items 和 nextCursor；目录未加载或认证失败会报错，不用空数组隐藏错误。

返回一页 Runtime：items 是当前页，nextCursor 用于继续查询。分页参数为 limit（默认50，1..100）和 cursor；认证/目录加载失败按错误返回。见 [列表查询与分页](/domain-model/page)。subscribeRuntimes 仍携带同步状态。
