`auth login` · CLI

通过 stdin 的 organizationId、username、password 登录无影用户态。成功后仅保存 LoginToken/sessionId/endUserId；不保存密码，失败保留原凭据；LOGIN_CHALLENGE_REQUIRED 退出 4，当前不承接后续挑战。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| Go | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| Java | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## 完整公开签名

### CLI · auth

```sh
wuying auth login
required --stdin — Read organizationId, username and password JSON; save only the resulting login tuple
```

## 结果、错误与生命周期

以本语言签名中的实际返回包装为准。快照保留投影；观察结束释放订阅；本地超时不代表远端未执行或已取消。涉及消息、交互与配置写入时，按原身份和实际回执核对结果。
