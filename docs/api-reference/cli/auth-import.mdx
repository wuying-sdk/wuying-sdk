`auth import` · CLI

通过 stdin 导入凭据。当前只支持 POSIX 私有 0600 明文文件，Windows 不支持持久导入；这不是钥匙串，也不验证在线身份。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| Go | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| Java | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| CLI | `wuying auth import` | 已公开声明，需核对环境能力 |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## 完整公开签名

### CLI · auth

```sh
wuying auth import
required --stdin — Read a credential JSON object from stdin
```
