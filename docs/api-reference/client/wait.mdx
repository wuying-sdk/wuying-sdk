`wait` · Client

AK/SK 管理员态等待指定桌面创建完成；使用原创建结果的 regionId 与 desktopIds，创建成功不等于 Agent 或 IM 在线。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `Client.wait` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go.Client.Wait` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.WuyingClient.wait` | 已公开声明，需核对环境能力 |
| CLI | `wuying desktops wait` | 已公开声明，需核对环境能力 |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface ExecutionContext {
    signal?: AbortSignal;
    traceId?: string;
    timeout?: number;
}

interface WaitDesktopsRequest {
    regionId: string;
    desktopIds: string[];
    pollIntervalMs?: number;
}

interface WaitDesktopsResponse {
    desktopIds: string[];
    ready: true;
}
```
