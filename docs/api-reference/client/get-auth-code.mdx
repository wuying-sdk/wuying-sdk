`getAuthCode` · Client

AK/SK 管理员态为已经核验映射的用户申请 AuthCode；不能在用户态 Client 调用，不能将取票接口开放为任意用户代签。凭据仅交给目标用户，不记录票据正文。

| 语言 | 公开入口 | 状态 |

| JavaScript / TypeScript | `Client.getAuthCode` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go.Client.GetAuthCode` | 已公开声明，需核对环境能力 |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。
