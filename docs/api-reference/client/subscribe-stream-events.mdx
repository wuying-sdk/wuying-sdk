`subscribeStreamEvents` · Client

只读订阅已启用的原始流事件；不赋予执行控制权，不替代消息与 Turn 的业务快照。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `Client.subscribeStreamEvents` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go.Client.SubscribeStreamEvents` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.WuyingClient.subscribeStreamEvents` | 已公开声明，需核对环境能力 |
| CLI | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。
