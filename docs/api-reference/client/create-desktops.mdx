`create` · Client

AK/SK 管理员态创建云桌面；服务端按真实权限处理。保留创建返回的订单/桌面身份后再 wait，未知结果时不能通过重复 create 恢复。此实例方法不同于初始化 Client 的静态工厂。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `Client.create` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go.Client.Create` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.WuyingClient.create` | 已公开声明，需核对环境能力 |
| CLI | `wuying desktops create` | 已公开声明，需核对环境能力 |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface ExecutionContext {
    signal?: AbortSignal;
    traceId?: string;
    timeout?: number;
}

interface CreateDesktopsRequest {
    regionId: string;
    officeSiteId: string;
    bundleId: string;
    policyGroupId?: string;
    desktopName?: string;
    amount?: number;
    endUserIds?: string[];
    userAssignMode?: 'ALL' | 'PER_USER';
    chargeType?: 'PostPaid' | 'PrePaid';
    period?: number;
    periodUnit?: 'Month' | 'Year';
    autoPay?: boolean;
    autoRenew?: boolean;
}

interface DesktopCreateOptions {
    wait?: boolean;
    pollIntervalMs?: number;
}

interface CreateDesktopsResponse {
    desktopIds: string[];
    orderId: string;
    requestId: string;
    /** True only after wait has verified all requested desktops as Running or Stopped. */
    ready?: boolean;
}
```
