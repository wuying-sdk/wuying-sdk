`stopAspStream` · ASP

停止当前 ASP 流化会话；不等于取消 Agent Turn。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `AspManager.stopAspStream` | 已公开声明，需核对环境能力 |
| Go | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| Java | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
| CLI | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## 完整公开签名

### JavaScript / TypeScript · AspManager

```ts
stopAspStream(): Promise<void>;
```
