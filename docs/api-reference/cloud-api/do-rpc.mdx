## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `CloudClient.doRPC` | 已公开声明，需核对环境能力 |
| Go | 本基线未匹配到相同命名/合同，查语言清单确认替代入口 | — |
