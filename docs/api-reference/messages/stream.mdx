`sendMessageStream` · Message

当前 JS 流交付 message / turn 快照，不承诺 text.delta 或 text.replace。保存受理身份；停止本地消费可退出迭代或使用 ctx.signal 结束等待，stream.cancel() 会请求远端取消，仍需核对终态。

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

interface SendRequest extends ConversationRef {
    text: string;
    clientCommandId?: string;
    inputParts?: InputPart[];
    targetMemberId?: string;
    attachmentIds?: string[];
    /** Structured references, routed by the existing Gateway group mention contract. */
    mentions?: {
        memberId: string;
    }[];
}

interface ConversationRef extends RuntimeRef {
    conversationId: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface MessageStream extends AsyncIterable<StreamChunk> {
    readonly accepted: Promise<MessageAccepted>;
    readonly result: Promise<Turn & {
        state: 'completed' | 'cancelled' | 'interrupted';
    }>;
    cancel(ctx?: Context): Promise<{
        state: 'requested' | 'cancelled' | 'already_finished';
    }>;
}
```
