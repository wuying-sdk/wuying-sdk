`listMessages` · Message

返回 Page&lt;Message&gt;，读取 items；同一轮可产生多条消息，按真实 ID 对账。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `ConversationManager.listMessages` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go/manager.ConversationManager.ListMessages` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.manager.ConversationManager.listMessages` | 已公开声明，需核对环境能力 |
| CLI | `wuying messages list` | 已公开声明，需核对环境能力 |
| Android | [`Methods.conversationListMessages`](/reference/android/models/conversation#listmessages) via `Client.request` | 移动 JSON 声明，需配套原生制品与环境能力 |
| iOS | [`Methods.conversationListMessages`](/reference/ios/models/conversation#listmessages) via `Client.request` | 移动 JSON 声明，需配套原生制品与环境能力 |

使用与当前身份相符的 Client，由宿主确认目标资源和访问范围。服务端代用户调用仍遵守用户态身份边界，见[授权与认证](/integration/01-auth-and-lifecycle)。

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

interface MessageQuery extends ConversationRef {
    cursor?: string;
    limit?: number;
}

interface ConversationRef extends RuntimeRef {
    conversationId: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface ListOptions {
    limit?: number;
    cursor?: string;
}

interface Page<T> {
    items: T[];
    nextCursor: string | null;
    projection?: Projection;
}

interface Message extends ConversationRef {
    messageId: string;
    clientMessageId?: string;
    turnId?: string;
    sender: Sender;
    blocks: Block[];
    state: 'pending' | 'streaming' | 'folded' | 'completed' | 'cancelled' | 'failed' | 'interrupted' | 'unknown';
    position: Int64;
    createdAt: Int64;
    revision: Int64;
    timing?: ExecutionTiming;
}

interface Projection {
    /** Scoped mode only: authorized control/protocol availability, independent of catalogs/history. */
    controlReady?: boolean;
    /** Present only with explicit scoped readiness; coverage refers to this domain. */
    readinessDomain?: 'agents' | 'models' | 'conversation' | 'summaries';
    phase: 'initializing' | 'ready' | 'stale' | 'resyncing' | 'unavailable';
    coverage: 'partial' | 'complete';
    generation: string;
    commitId?: string;
    viewVersion: string;
    statusVersion: string;
    lastSyncedAt?: Int64;
}
```
