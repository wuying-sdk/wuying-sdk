`createConversation` · Conversation

req 明确 runtimeId 和 mode：single 使用 agentId，group 使用真实成员信息；mutationId 由宿主在发起前生成并保存。结果未知时查询原请求，不能换 ID 重建。

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

type CreateRequest = (CreateBase & {
    mode: 'single';
    agentId: string;
    subAgentId?: string;
}) | (CreateBase & {
    mode: 'group';
    coordinatorAgentId?: string;
    members: {
        agentId: string;
        displayName?: string;
        modelId?: string;
        responsibility?: ResponsibilityPatch;
        clientMemberKey?: string;
    }[];
});

interface CreateBase extends RuntimeRef {
    name: string;
    config?: Config;
    workspaceId?: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface MutationOptions {
    mutationId: string;
}

interface CreatedConversation extends ConversationRef {
    coordinatorMemberId?: string;
    memberMappings?: {
        clientMemberKey: string;
        memberId: string;
    }[];
    mappingState?: 'complete' | 'unknown';
}

interface ConversationRef extends RuntimeRef {
    conversationId: string;
}
```
