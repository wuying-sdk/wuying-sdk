`listAgents` · Agent

req.runtimeId 来自已授权目录；读取 items 当前页并保留 projection，不自动选择第一项。

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `AgentManager.listAgents` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go/manager.AgentManager.ListAgents` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.manager.AgentManager.listAgents` | 已公开声明，需核对环境能力 |

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface ListOptions {
    limit?: number;
    cursor?: string;
}

interface Page<T> {
    items: T[];
    nextCursor: string | null;
    projection?: Projection;
}

interface Agent extends AgentRef {
    name: string;
    enabled: boolean;
    availability: 'available' | 'unavailable' | 'unknown';
    /** Product role from the selected Gateway route, not inferred from its name. */
    category?: 'primary' | 'agent';
    /** Original probe reason; preserves not_installed separately from unavailable. */
    probeStatus?: string;
    capabilities: {
        group: Capability;
        modelConfig: Capability;
        cancel: Capability;
        resources: Capability;
    };
    presentation?: AgentPresentation;
    revision: Int64;
}

interface AgentRef extends RuntimeRef {
    agentId: string;
}

interface Projection {
    /** Scoped mode only: authorized control/protocol availability, independent of catalogs/history. */
    controlReady?: boolean;
    /** Present only with explicit scoped readiness; coverage refers to this domain. */
    readinessDomain?: 'agents' | 'models' | 'conversation' | 'summaries';
    phase: 'initializing' | 'ready' | 'stale' | 'resyncing' | 'unavailable';
    coverage: 'partial' | 'complete';
    generation: string;
    commitId?: string;
    viewVersion: string;
    statusVersion: string;
    lastSyncedAt?: Int64;
}
```
