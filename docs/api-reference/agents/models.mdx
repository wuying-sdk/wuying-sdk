`listAgentModels` · Agent

使用同一 Runtime 下的真实 agentId；此目录不同于独立云 ModelConfig。

## 语言与授权

| 语言 | 公开入口 | 状态 |
|---|---|---|
| JavaScript / TypeScript | `AgentManager.listAgentModels` | 已公开声明，需核对环境能力 |
| Go | `github.com/aliyun/wuying-sdk-go/manager.AgentManager.ListAgentModels` | 已公开声明，需核对环境能力 |
| Java | `com.aliyun.wuying.sdk.manager.AgentManager.listAgentModels` | 已公开声明，需核对环境能力 |
| CLI | `wuying models list` | 已公开声明，需核对环境能力 |
| Android | [`Methods.agentListAgentModels`](/reference/android/models/agent#listagentmodels) via `Client.request` | 移动 JSON 声明，需配套原生制品与环境能力 |

## TypeScript 参数与结果结构

以下结构直接摘自同版本声明；继承的身份字段一并列出。嵌套类型与完整数据字段见[类型声明](/reference/js/types)，Go / Java 以各自真实 DTO 为准。

```ts
interface Context {
    signal?: AbortSignal;
    timeout?: number;
    traceId?: string;
}

interface AgentRef extends RuntimeRef {
    agentId: string;
}

interface RuntimeRef {
    runtimeId: string;
}

interface ListOptions {
    limit?: number;
    cursor?: string;
}

interface Page<T> {
    items: T[];
    nextCursor: string | null;
    projection?: Projection;
}

interface Model extends ModelCapabilities {
    modelId: string;
    name: string;
    available: boolean;
    revision: Int64;
    providerName?: string;
    isDefault?: boolean;
}

interface ModelCapabilities {
    groupName?: string;
    sortOrder?: number;
    description?: string;
    features?: Record<string, boolean>;
    thinking?: {
        supported: boolean;
        required?: boolean;
        defaultValue?: string;
        options: {
            value: string;
            label: string;
        }[];
    };
    inputModalities?: string[];
}

interface Projection {
    /** Scoped mode only: authorized control/protocol availability, independent of catalogs/history. */
    controlReady?: boolean;
    /** Present only with explicit scoped readiness; coverage refers to this domain. */
    readinessDomain?: 'agents' | 'models' | 'conversation' | 'summaries';
    phase: 'initializing' | 'ready' | 'stale' | 'resyncing' | 'unavailable';
    coverage: 'partial' | 'complete';
    generation: string;
    commitId?: string;
    viewVersion: string;
    statusVersion: string;
    lastSyncedAt?: Int64;
}
```
