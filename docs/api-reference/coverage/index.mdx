## 统计口径

- 模型操作覆盖根 Client、各 Manager、流/订阅对象、服务端签名、语言专属高级入口和 CLI 叶命令。
- 构造、工厂、配置、DTO/错误辅助与回调实现契约仍完整列在语言清单，避免把它们混作资源操作。
- 不包括 internal 私有实现、非 public Java 编译类、测试/示例/生成工具，或尚未交付的规划接口。
- Java 以当前 public 签名和源注解快照为准；Go 包含公开类型别名的可见方法；JS 包含 Manager 返回接口的继承方法。

## 更新检查

声明变化后重新快照并生成；覆盖检查要求所有已发现公开条目有文档落点，并校验生成内容。覆盖清单和模型页使用同一输入基线，完整语言参考保持原有地址。
