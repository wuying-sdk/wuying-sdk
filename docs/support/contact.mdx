## 项目与问题反馈

访问 [Wuying SDK GitHub 项目](https://github.com/wuying-sdk/wuying-sdk)，查看项目说明与维护方公布的反馈渠道。

反馈接入问题时，请提供 SDK 版本、编程语言、操作系统、发生步骤、预期与实际结果，以及脱敏后的错误码和请求标识。排查方法见[排障与支持](/support/troubleshooting)。

请勿在公开渠道提交 AK/SK、AuthCode、LoginToken、密码、SDK 数据库或业务内容。安全问题请通过现有交付渠道私下联系维护团队，专用安全报告渠道确认后会在这里公布。
