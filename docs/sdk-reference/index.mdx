从左侧 SDK 下拉选择 **JavaScript / TypeScript、Go、Java、Android、iOS 或 CLI**，查看该语言的类/接口目录、完整公开清单与原始签名。按业务模型查操作进入 [API Reference](/api-reference/index)，全量范围与覆盖证据见[覆盖清单](/api-reference/coverage/index)。

移动端入口见 [Android](/sdk-reference/android) 与 [iOS](/sdk-reference/ios)；使用各自原生包装与配套 Go 引擎制品，发布和验证范围见[移动合同](/reference/mobile/contract)。

按同版本、同语言查精确签名、DTO、参数与返回值。

[本语言 API / 类型 / 命令入口](/domain-model/language-bindings) 同时提供安装和完整示例。Go 对照公共 package，Java 对照公开方法与离线 Javadoc，JS 对照根导出与 index.d.ts，CLI 对照已实现子命令。单语言包只链接自己包含的绑定。

领域职责与状态机见 [领域模型](/domain-model/00-overview)；完成任务的步骤见 [指南](/guides/index)。不要从 Manager 数量推断业务对象数量，也不要将未公开的内部接口作为 API。

版本由该交付的 manifest / SHA256SUMS 标识；npm/Maven 的展示版本不单独证明源码一致。GitHub 和公共包仓库尚未指定时，以随包制品为安装来源。
